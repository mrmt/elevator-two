# シーン定義

D-11 で決めたとおり、シーンは名前付きの定義を持つ。定義が骨格を与え、その内側を自動生成が
埋める。elevator-one の `PRESETS` と同じ考え方で、命名も漢字1〜2文字 + 英語スラッグを踏襲する。

数値はいずれも暫定。実装して鳴らしながら詰める。

## キット

D-10 の合成方式は共通で、パラメータの振り方だけが違う。

- **深 deep** — BD の減衰を長く取り、ピッチ落ちを深くする。リムとノイズ系パーカッション主体。
  HH は控えめで暗い。陰のシーン用
- **硬 hard** — BD は短くクリックを強調。クラップと金属質の HH。冷たく硬い質感
- **温 warm** — BD をやわらかく、アタックを丸める。FM のパーカッシブ音とシェイカー。
  ジャズ / ボッサ回路との相性を優先する
- **電 electro** — TR-808 に最も忠実。カウベルとオープン HH を使う。electro funk 局面用

## 群ごとの狙い

### スタブ回路 — 陰 (潜行 / 苔 / 霜 / 鼓動)

BPM 118〜122。ディレイのフィードバックが表情の中心。ベースは低音域で音価が長く、
フィルタはゆっくり大きくうねる。

- **潜行 submerge** — 最深部。キック・サブベース・スタブのみ。ディレイは発振寸前で保つ
- **苔 moss** — 中域のノイズパーカッションが増える。`dub-out` が最も頻出する
- **霜 frost** — 高域のグリッチと金属質のパーカッション。同じ陰でも冷たい側
- **鼓動 pulse** — キック強め。ベースのフィルタが大きくうねる。陰だが体は動く。
  陽の群への出入口になる

### 持続回路 — 陽 (遠望 / 曙 / 陽炎 / 疾走 / 祝祭)

BPM 124〜132。D-9 のレイヤー累積が主役。ベースは中音域で音価が短く、フィルタは
16分単位で細かく動く。

- **遠望 vista** — ゆっくり積む。層が薄く広い。陽の入口
- **曙 daybreak** — add9 の持続。レイヤー累積の基本形。最も素直な高揚
- **陽炎 shimmer** — 高域のリフ主体。フィルタが揺れ続ける
- **疾走 dash** — 最速。アルペジオ主体で累積が速い
- **祝祭 jubilee** — 天井まで積んで `drop` を繰り返す。最も派手。陰陽軸の頂点

### ジャズ / ボッサ回路 — 彩り (微睡 / 夕暮 / 硝子)

D-9 のとおり、この回路は主役シーンと差し込みの両方を持つ。ここは主役側の定義。

- **微睡 drowse** — 最も遅い。ゆるい ii-V。エレピが主役
- **夕暮 dusk** — maj9 とボサ的シンコペ。彩りが主役を張る典型
- **硝子 glass** — テンション和音を短く刺す。ジャズと dub の中間に位置する

### electro funk (跳躍 / 鋼)

D-3 の B 要素の担当。ハーモニーは持続回路を薄く敷くだけで、ベースとリズムが前に出る。

- **跳躍 bounce** — 808 のシンコペ、ベース主導
- **鋼 steel** — 硬質。グリッチを多く出す

## 実装の順

4群からまず1つずつ作り、鳴りの差が出ることを確認してから埋める。

1. 潜行 submerge (陰の基準点)
2. 曙 daybreak (陽の基準点)
3. 夕暮 dusk (彩り)
4. 跳躍 bounce (B 要素)

残る10種はこの4つのパラメータを振って作る。
