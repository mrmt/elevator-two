# Elevator Two

自動生成のエレクトロを鳴らし続けるシングルファイルの楽器。
[elevator-one](https://github.com/mrmt/elevator-one) の技術的な骨格を踏襲しつつ、音楽的には別物を目指す。

**最新版: v0.3** — 変更点は下の[変更履歴](#変更履歴)を参照。

音を鳴らすだけならネットワークには一切繋がない。
背景に動画を流す機能 (音作りタブの「背景」) を使うときだけ YouTube へ繋がる。
その場合は YouTube Data API のキーが要る (画面から入れる。このブラウザにだけ保存される)。

`index.html` をブラウザで開き、右上の再生ボタンを押すと鳴りはじめる。
シーンが数分ごとに移り、16小節ごとにフレーズが変わり、4小節の節目にブレイクや
フィルタが入る。いま何が起きているかは XY パッドの下に表示される。
XY パッドの背景にはいま出ている波形が出る。
見た目は3つのテーマから選べる (音作りタブの「見た目」)。

設計の議論と決定は [docs/DESIGN.md](docs/DESIGN.md) に集約している。
D-1 から順に決定事項を積み、末尾に実装の順序を記した。
シーンの定義は [docs/SCENES.md](docs/SCENES.md)、実装の構造は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)、
テストは [docs/TESTING.md](docs/TESTING.md) に分けてある。
背景動画の検索語を手で試す `tools/yt-probe.sh` もある。

## 目指すもの

- minimal techno を土台に、electro funk / dub techno / グリッチを混ぜる
- ベースが中核。TB-303 的なアシッドではなく、Minimoog 的な厚く粘るフィルタの動き
- ドラムは TR-808 系のアナログ発音方式を自前合成。サンプルは持たない
- ハーモニーは3つの独立回路 (dub のスタブ / 高揚する持続 / ジャズ・ボッサの彩り)
- 数分ごとに曲調が変わり、4 / 8 / 16 小節の節目にブレイクやフィルタが入る

## elevator-one との関係

| | elevator-one | elevator-two |
| --- | --- | --- |
| 音楽 | アンビエント / ミニマル / ドローン | エレクトロ (minimal techno を土台に electro funk / dub techno / グリッチを混ぜる) |
| 時間軸 | 漂い続ける。明確な展開を持たない | 数分ごとの曲調変化と、4 / 8 / 16 小節ごとのブレイク |
| リズム | 独立した16ステップシーケンサ1系統 | 4つ打ちを基本とする多トラック構成 (生成方式は検討中) |
| 実装 | 単一 `index.html`、ビルド工程なし | 同左を踏襲 |

コードは共有せず、one から土台をコピーして分岐させる。共通化のための仕組みは持たない。

## 変更履歴

### v0.3 (2026-09-11)

聴いた結果の調整と、見た目まわりの追加。

**音**
- エレピを作り直した。FM の金属質な音 (v0.2) をやめ、Juno-106 のようなパルス幅変調の
  矩形波にコーラスを掛けた音へ。さらにディケイを詰め、フィルタも同じ速さで閉じて歯切れを出した (D-40 / D-41)
- インダストリアル・ノイズの層を足した。16分5〜15個または8分5〜7個の周期で回るので
  小節に乗らず、ポリリズムになる。音色は1音ごとに不規則に振り、7割は左右で独立した周期を持つ (D-38)
- コード弾きに連打のバリエーションを足した。持続音の代わりに短い和音を刻み、
  専用の ping-pong ステレオディレイへ送る (D-34)
- ベースを整えた。音程が動かない小節ではフィルタとレゾナンスを1音ごとに大きく振り、
  音符が5未満の小節ではフェーザーで補う。全体の量は少し下げた (D-39 / D-42)
- フェーザーとシーケンス掃引を第3層イベントに追加。掃引は35%の確率でレゾナンスを
  発振寸前まで上げる (D-28 / D-29)
- ベースのタイトな音色を、シーンによらず半々で引くようにした (D-25)
- スライダーの既定値を変更 (重さ0.1 / 空間0.1 / グリッチ0.9 / 展開0.9 / 変異0.8 / 推移時間5s)

**見た目**
- XYパッドの背景にオシロスコープを置いた (D-36)
- UIのテーマを3つにした。既定 (海) / TE (ミニマル & インダストリアル) /
  EK (ダーク & サイバネティクス) (D-37)

**背景の動画**
- XYパッドの背景に YouTube の動画を流せるようにした。シーンの英語名と性格を表す語で
  CC BY の動画を探し、4小節ごとにクロスフェードで差し替える (D-32 / D-33)
- API キーはユーザーが画面から入れ、このブラウザにだけ保存する。キーが無ければ一切通信しない
- 検索結果を30日取っておき、日々の手入れは `videos.list` (1単位) で行う。
  `search.list` は100単位なので、消費を1/20以下に抑えた (D-35)
- 検索語を手で試す `tools/yt-probe.sh` を置いた

### v0.2 (2026-09-10)

初めて通して聴いたあとの調整。

- ベースが和音を無視していたのを直した。度数をいま鳴っている和音から引き、
  ルートを基本にする。あわせて音域の基準がずれていた (12の倍数でなかった) のを修正 (D-17)
- ベースの旋律が動きすぎていたのを抑え、2小節以上は同じ形を保つようにした (D-19 / D-30)
- ベースの厚みをパルス幅変調で作り、サスティンを持たないタイトな音色を加えた (D-18 / D-25)
- 並びが切り替わる前の小節にオカズを置くようにした。35%の確率で次の小節へはみ出す (D-20)
- 16分のシーケンスと、その専用ステレオディレイを足した (D-21)
- ブレイクが何小節も続くのをやめ、長くて1小節に収めた (D-24)
- シーン構成を electro funk へ寄せた (持続/陽を2つ減らし funk に歯車・火花を追加) (D-31)
- 並びを種から決めるようにして、ミニマルに要る反復が出るようにした (D-14)

### v0.1 (2026-09-10)

設計 (D-1 〜 D-13) と、実装順序 1〜8 のひと通り。

- 進行の3階層 (シーン / フレーズ / イベント) と、陰陽を20〜40分で往復する長周期の波
- TR-808 に倣ったドラム音源 (キット4種) と、トラックごとに方式を変えるリズム生成
- Ladder フィルタ (AudioWorklet) を核にしたベース
- ハーモニー3回路 (持続 / スタブ / ジャズ・ボッサ)
- シーン14種と、遷移3方式 (ブレイク / 連続変形 / DJミックス風)
- 操作UI (XYパッド = 陰陽 × 密度、スライダー、シーン一覧と次へ)
